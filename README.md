# maze-designer (3D 迷宮設計與冒險系統)

模擬社團 10×10 地圖、用隔板組成迷宮的 PHP 專案。結合 Three.js 即時 3D 視角探索、2D 互動式迷宮地圖編輯器、排位計時競速賽與帳號管理功能。

---

## ✨ 核心特色

- **10×10 社團迷宮模擬**：支援社團規格隔板配置與自由繪製。
- **3D 即時視角**：利用 Three.js 提供第一人稱走迷宮體驗與俯瞰視角，搭配 2D 雷達小地圖導航。
- **2D 地圖編輯器**：支援 5×5 至 30×30 各種規格，可自由雕刻路徑、設置起終點，亦可一鍵自動生成迷宮。
- **排位計時挑戰**：提供 10×10、15×15、20×20、25×25、30×30 題庫與排行榜最佳紀錄競速。
- **帳號權限管理**：訪客可試玩基礎地圖，註冊登入後解鎖全尺寸規格與雲端個人地圖存檔。

---

## 🛠️ 技術架構

- **前端**：HTML5 / CSS3 / JavaScript (ES6+), [Three.js](https://threejs.org/)
- **後端**：PHP 7.4+ / 8.x
- **資料庫**：MySQL / MariaDB
- **推薦伺服器環境**：XAMPP (Apache + MySQL)

---

## 🚀 快速安裝與使用

### Windows（XAMPP）

1. 將本專案放置於 XAMPP 的 `htdocs/3Dmaze` 目錄。
2. 啟動 XAMPP Control Panel 的 **Apache** 與 **MySQL**。
3. （選用）可複製 `config.example.php` 為 `config.php` 自訂資料庫帳號與密碼。預設使用本機 `root` 與無密碼連線。
4. 打開瀏覽器訪問 `http://localhost/3Dmaze/` 即可開始使用（資料庫與資料表將自動建立）。

### macOS（Homebrew）

1. 安裝 PHP 與 MySQL：`brew install php mysql`
2. 啟動 MySQL：`mysql.server start`
3. 在專案資料夾執行 `php -S localhost:8000`，打開 `http://localhost:8000/`

---

## 🎮 控制說明

- **W / A / S / D** 或 **方向鍵**：移動角色
- **空白鍵 (Space)**：跳躍
- **滑鼠拖曳**：旋轉 3D 視角
- **滑鼠滾輪**：縮放自由相機

## 版本歷程

### v2.2（目前版本）
- 新增 30×30「傳奇級」排位賽規格，挑戰限時 40 分鐘（2400 秒）。
- 排位賽大廳與排行榜新增 30×30 項目，支援記錄全服名次與個人最佳成績。
- 收錄 4 張官方 30×30 排位賽地圖（含經典長路徑與中央終點神殿挑戰）。
- 優化 3D 視角俯瞰縮放距離，支援完整瀏覽 30×30 大規格迷宮全貌。
- 支援中高級使用者發布與審核 30×30 排位賽地圖。

### v2.1
- 推出使用者權限體系：分為初級、中級、高級三級（新註冊預設為初級）。
- 初級使用者可儲存個人地圖，支援輸入他人分享碼載入迷宮。
- 中級使用者可發行 1 分鐘限時分享碼（上限 3 人使用，具備即時倒數與人數統計），並可投稿排位賽地圖（每類最多 3 張）。
- 高級使用者專屬「帳號管理」功能，可隨時調整初級與中級使用者權限（高級帳號安全隱藏）。
- 高級使用者專屬「排位賽地圖審核與管理」功能，支援 2D 地圖縮圖預覽、審核通過／退回，以及刪除官方排位地圖。
- 排位賽地圖審核視窗擴展加寬，官方題庫列表之操作與刪除按鈕直接呈現免捲動。
- 3D 模擬試跑完賽計時器移至操控列正中央，閱讀更清晰且不被懸浮控制遮擋。

### v2.0
- 全站介面改版：統一的深色設計、顏色、字型、按鈕與線條圖示，畫面上不再使用 emoji。
- 頂部列只留名稱、「練習／排位賽」切換、排行榜與帳號選單（我的地圖庫、我發布的排位地圖數、登出）。
- 練習模式：規格、地圖、檔案三個下拉選單；牆壁、起點、終點、平移改為左側工具欄，並新增快捷鍵說明。
- 3D 面板：視角在左上、外觀與計時收進設定選單，試跑、停止、回起點與計時器整合在底部操控列。
- 排位賽：新增賽前大廳；比賽開始後 3D 佔滿畫面並顯示大字倒數。
- 結算畫面與所有對話框（登入、排行榜、地圖總覽、發布、儲存、我的地圖庫）改為同一套樣式，文字更簡短。
- 支援平板：寬度 1023px 以下改為上下排列，觸控裝置試跑時會出現方向鍵與跳躍鍵。
- 3D 畫面更流暢：效能普通的電腦也能順跑；修正轉動視角時白色底板閃爍的問題。
- 收錄 25×25 官方排位賽地圖 #4。
