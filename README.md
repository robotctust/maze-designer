# maze-designer (3D 迷宮設計與冒險系統)

模擬社團 10×10 地圖、用隔板組成迷宮的 PHP 專案。結合 Three.js 即時 3D 視角探索、2D 互動式迷宮地圖編輯器、排位計時競速賽與帳號管理功能。

---

## ✨ 核心特色

- **10×10 社團迷宮模擬**：支援社團規格隔板配置與自由繪製。
- **3D 即時視角**：利用 Three.js 提供第一人稱走迷宮體驗與俯瞰視角，搭配 2D 雷達小地圖導航。
- **2D 地圖編輯器**：支援 2×2 至 50×50 各種規格，可自由雕刻路徑、設置起終點，亦可一鍵自動生成迷宮。
- **排位計時挑戰**：提供五大標準段位（10×10～30×30）、長方形「特殊賽」與 35×35～50×50「巔峰賽」題庫與全服排行榜競速。
- **帳號權限管理**：訪客可試玩基礎地圖，註冊登入後解鎖全尺寸規格與雲端個人地圖存檔。

---

## 🛠️ 技術架構

- **前端**：HTML5 / CSS3 / JavaScript (ES6+), [Three.js](https://threejs.org/)
- **後端**：PHP 7.4+ / 8.x
- **資料庫**：MySQL / MariaDB
- **推薦伺服器環境**：XAMPP (Apache + MySQL)

## 📁 專案結構

```
index.php              入口：組合 views/ 的畫面並依序載入 CSS、JS
config.example.php     資料庫設定範本（複製成 config.php 使用）
api/                   後端 API（回傳 JSON）
  auth.php             登入、註冊、登出、登入狀態
  maps.php             個人地圖的儲存、讀取、刪除
  ranked.php           排位賽地圖、成績、排行榜、發布
  share.php            分享碼產生與兌換
  admin.php            高級使用者：帳號管理、地圖審核
includes/              後端共用程式
  db.php               資料庫連線與自動建表
  api_bootstrap.php    每支 API 共用的開頭
views/                 畫面區塊（頂部列、編輯區、排位大廳、3D 面板）
  dialogs/             各種對話框
assets/
  css/                 樣式，依畫面區塊分檔（載入順序見 index.php）
  img/                 地圖底圖
  icons.svg            線條圖示
  js/lib/              外部套件（three.js）
  js/core/             2D 編輯器、3D 引擎、排位特效
  js/app/              頁面功能，依功能分檔，共用同一個全域範圍，載入順序見 index.php
data/ranked_maps/      官方排位賽地圖（依規格分資料夾）
schema.sql             資料表結構參考
```

## 🚀 快速安裝與使用

### Windows（XAMPP）

1. 將本專案放置於 XAMPP 的 `htdocs/3Dmaze` 目錄。
2. 啟動 XAMPP Control Panel 的 **Apache** 與 **MySQL**。
3. （選用）可複製 `config.example.php` 為 `config.php` 自訂資料庫帳號與密碼。預設使用本機 `root` 與無密碼連線。
4. 打開瀏覽器訪問 `http://localhost/3Dmaze/` 即可開始使用（資料庫與資料表將自動建立）。

### macOS（Homebrew）

1. 安裝 PHP 與 MySQL：`brew install php mysql`
2. 在 Finder 雙擊專案資料夾裡的 `start.command`（或在終端機執行 `./start.command`），會自動啟動 MySQL 與網站並打開 `http://localhost:8000/`。要停止時在該視窗按 Ctrl+C。

## 🎮 控制說明

- **W / A / S / D** 或 **方向鍵**：移動角色
- **空白鍵 (Space)**：跳躍
- **滑鼠拖曳**：旋轉 3D 視角
- **滑鼠滾輪**：縮放自由相機
